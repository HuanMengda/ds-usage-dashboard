金额 · Token
数据来源：%DSH_HOME%\sessions 会话日志（多帧 zstd 压缩 JSONL，逐轮次含 provider 用量字段）。默认每 10 秒自动检查，DSH 写入新日志后自动重新统计并刷新页面（可切换 30/60 秒或关闭；展开状态不丢失）。
金额 = Token 用量 × 分时段单价（元 / 百万 token），高峰时段按北京时间每日 9:00–12:00、14:00–18:00 判定，以每次模型调用的开始时间为准；可在「计价设置」中按官方价目表校正。

计价设置（元 / 百万 Token）

计费公式：金额 = 输入 × 输入单价 + 缓存命中 × 缓存单价 + 输出 × 输出单价 + 推理 × 推理单价（均 ÷ 1,000,000）。
· 高峰时段为每日 9:00–12:00、14:00–18:00（北京时间），其余为空闲时段；按每次模型调用的开始时间判定时段。
· 默认价为 DeepSeek V4 系列官方价目表（2026-08 调价后），缓存命中按命中优惠价、未命中按常规输入价。
· 官方输出单价已含推理 token（默认推理单价为 0）；若你的账单对推理单独计费，请填写相应数值。
· 设置保存在浏览器本地（localStorage），可随时恢复默认。
