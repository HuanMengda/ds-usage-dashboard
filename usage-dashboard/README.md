# DSH 对话用量统计面板

一个零依赖的小工具：自动统计 **DeepSeek Harness（DSH）** 每次对话消耗的 Token 与金额，
按 **工作区 → 会话 → 每次回答** 层级展示，包含饼图、折线图、模型分列、时段计价。

- 数据完全来自**本机 DSH 会话日志**（详见下文"数据来源"），不上传、不联网。
- 金额按 **DeepSeek 官方价目表 + 高峰/空闲时段** 计算，可随时在页面内校正单价。
- 纯原生 HTML/JS/SVG 手绘图表，**无任何第三方依赖**。

## 目录结构

```
usage-dashboard/
├─ dashboard.html        # 统计面板页面（浏览器打开）
├─ generate-data.mjs     # 数据生成器：扫描会话日志 → dsh-data.json / dsh-data.js
├─ serve.mjs             # 本地服务器：自动重扫 + 自动更新数据
├─ start-dashboard.cmd   # 一键启动（推荐）
├─ 启动统计面板.cmd       # 一键启动（中文名版本，效果相同）
└─ README.md
```

## 运行要求

| 项 | 要求 |
|---|---|
| 系统 | Windows（其他系统需手动用 Node 运行，见下） |
| Node.js | **≥ 22.15（推荐 24.x）**，需内置 zstd 解压（`node:zlib`） |
| DSH | 本机已使用过 DeepSeek Harness，存在会话日志目录 `%USERPROFILE%\.dsh\sessions` |

> 查看 Node 版本：`node -v`。若版本过低，运行时会报 `zstdDecompressSync is not a function`。

## 快速开始

1. 解压本包到任意目录（路径随意，中文/空格均可）。
2. 双击 **`start-dashboard.cmd`**（或中文名版）。
3. 浏览器自动打开 `http://127.0.0.1:3488/`，即可看到统计页面。

页面默认每 10 秒自动检查数据、自动更新；DSH 每写入一条新对话记录，统计随之刷新
（右上角可切换 30/60 秒或关闭，也可点「刷新数据」手动强制重扫）。

### 手动方式（可选）

```powershell
# 1. 生成数据（扫描本机 ~/.dsh/sessions）
node generate-data.mjs

# 2. 启动服务（默认端口 3488，自动打开浏览器）
node serve.mjs

# 指定端口 / 不自动开浏览器
node serve.mjs --port 3489 --no-open
```

也可以不用服务器、直接双击 `dashboard.html` 打开——但那是**静态快照**，不自动更新；
请先运行 `node generate-data.mjs` 生成 `dsh-data.js`。

## 使用说明

- **顶部卡片**：累计金额、累计 Token、对话轮次（每次回答）、会话数、工作区数。
- **筛选用**：时间范围（全部/近7天/近30天/本月/自定义）、模型多选、是否含子代理会话、关键词搜索。
- **饼图**：按模型 / 按工作区的金额或 Token 分布。
- **折线图**：每日趋势（按模型分列，可切换金额/Token；跨度超 60 天自动按周聚合）。
- **层级列表**：工作区 → 会话 → 每次回答（T1/T2…）→ 每次模型调用明细；
  每步显示开始时间、耗时、模型、**时段（高峰/空闲）**、输入/缓存/输出/推理 Token、金额。
- **计价设置**（右上角按钮）：修改单价后所有金额实时重算，设置保存在浏览器本地。

## 计价口径（与官方一致，可校正）

高峰时段：北京时区 **每日 9:00–12:00 与 14:00–18:00**，其余为空闲；按**每次模型调用的开始时间**判定。

官方单价（元 / 百万 token，2026-08 调价后）：

| 模型 | 时段 | 输入（未命中） | 缓存命中 | 输出 |
|---|---|---|---|---|
| deepseek-v4-flash | 空闲 | 1.5 | 0.05 | 4.5 |
| | 高峰 | 3.0 | 0.10 | 9.0 |
| deepseek-v4-flash-vision-exp | 空闲 | 1.5 | 0.05 | 4.5 |
| | 高峰 | 3.0 | 0.10 | 9.0 |
| deepseek-v4-pro | 空闲 | 4.5 | 0.15 | 13.5 |
| | 高峰 | 9.0 | 0.30 | 27.0 |

- 公式：金额 = 输入×输入价 + 缓存命中×缓存价 + 输出×输出价 + 推理×推理价（均 ÷ 1,000,000）。
- DeepSeek 输出单价**已含推理 token**，故推理单价默认为 0；若另行单列请在计价设置中填写。
- 未列出的模型默认按 flash 档计价，追加到「计价设置」即可。

## 数据来源（隐私说明）

所有 Token 与时间数据来自本机 DSH 会话日志：

```
%USERPROFILE%\.dsh\sessions\<工作区>\<会话>\session.jsonl.zstd
```

该文件是 DSH 原生持久化的多帧 zstd 压缩 JSONL，其中的 `usage` 字段即 DeepSeek API 返回的
原始用量（输入/缓存命中/输出/推理 Token），由 DSH 适配器直接落盘，**与 API 口径完全一致**；
Token 数不是估算。金额为页面按上述价目表离线计算（官方不提供按次账单）。

**本包不含任何账号凭据、API Key 或您的对话内容**；打包版本也不包含数据快照，
首次运行自动扫描使用者的本机日志。

## 常见问题

- **端口被占用**：`node serve.mjs --port 3490`，浏览器打开 `http://127.0.0.1:3490/`。
- **页面提示"未找到数据"**：先确认本机有 `%USERPROFILE%\.dsh\sessions`，再双击启动脚本；
  或先手动运行 `node generate-data.mjs`。
- **金额与账单对不上**：优先检查「计价设置」单价与官方最新价目表是否一致；
  高峰/空闲按北京时间判定，若机器系统时间不准，边界时段（9:00/12:00/14:00/18:00 附近）可能有偏差。
- **想换端口/开启本机外访问**：DSH_HOME 环境变量可指定其他数据目录；`serve.mjs` 默认只监听 127.0.0.1。
